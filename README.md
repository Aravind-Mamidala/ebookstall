# EbookStall – Online Bookstore

**Tech Stack:** MERN (MongoDB, Express, React, Node), EJS, Bootstrap

**Live Demo:** https://ebookstall-backend.onrender.com/books  
**GitHub:** https://github.com/Aravind-Mamidala/ebookstall

## Overview
EbookStall is a dynamic e-commerce platform tailored for engineering students to browse and buy academic books.

## Features
- Admin-only book uploads  
- Department-based filtering & book details  
- Session-based secure cart with login/signup  
- User review system  
- Mobile-responsive layout with FontAwesome icons

## Setup
1. Clone repo  
2. `npm install`  
3. `npm run dev`  
4. Open `localhost:3000` in your browser
